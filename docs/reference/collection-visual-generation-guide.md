# 合集视觉资源生成指南

## 用途

本文档用于新增或重做博客合集的日间/夜间封面图、竖长封面视频和页面背景图。提示词不绑定具体模型，可用于常见图片生成、图片编辑和图生视频工具。

运行时字段：

| 资源 | 字段 | 比例 | 页面用途 |
|---|---|---:|---|
| 日间/夜间竖长封面图 | `coverImageUrl` | 9:16 | 合集列表缩略图、选中态、详情页、Open Graph |
| 日间/夜间竖长封面视频 | `coverVideoUrl` | 9:16 | 首页选中态和详情页竖长封面槽 |
| 日间/夜间页面背景图 | `backgroundImageUrl` | 16:9 | 合集详情页首屏静态空间背景 |
| 合集首页背景图 | `TbConfig: collections.home.background.day/night` | 16:9 | `/collections` 整页环境背景 |

不生成或配置独立视频 Poster，不使用 16:9 背景视频。

## 统一视觉约束

### 品牌语气

- 关键词：长期写作、个人知识档案、克制的技术感、真实使用痕迹、可持续积累。
- 日间：自然光、低饱和材质、清晰但不过曝、偏编辑设计与实体档案。
- 夜间：蓝黑环境、冷青细节光、克制的数字界面感，避免廉价霓虹和彩色灯带堆叠。
- 同一合集的昼夜资源必须保留相同主体、镜头、构图和视觉锚点，只改变时间、光线和材质反馈。

### 禁止项

- 不生成任何文字、字母、数字、Logo、水印、二维码或伪 UI。
- 不使用知名品牌、影视、游戏角色或可识别公众人物。
- 不把手机、书脊、海报标题当作主要信息载体。
- 不使用夸张景深、鱼眼、倾斜地平线、过度辉光或高频粒子。
- 不让关键主体贴近边缘；上下各保留约 8% 安全区，左右各保留约 10% 安全区。

## 竖长封面图

### 输出规范

- 比例：严格 9:16。
- 建议尺寸：`1440 × 2560`；最低 `900 × 1600`。
- 单一明确主体，允许有纵向空间层次，但不能像手机界面或细长尺子。
- 中央 60% 区域保留稳定视觉锚点，适合 `object-fit: cover` 下轻微裁切。
- 图片本身不包含合集标题，标题由网页语义化文本展示。

### 日间封面通用提示词

```text
为个人技术博客的文章合集创作一张高级、克制、可长期使用的竖版主题封面。

合集名称：{合集名称}
合集描述：{合集描述}
内容关键词：{3-6 个关键词}
核心视觉隐喻：{与主题有关的真实空间、器物、材料或自然景观}

严格 9:16 竖版构图，单一明确主体，具有前景、中景和背景层次，主体位于中央安全区。自然日光，低饱和但不灰暗，材质真实，细节精致，像高质量编辑摄影与实体档案设计的结合。画面安静、有长期积累感，不做宣传海报，不出现人物特写。为网页叠加标题保留稳定的低细节区域。

不要生成任何文字、字母、数字、Logo、水印、二维码、边框、手机界面、书名或伪 UI。不要过度景深、过曝、高饱和、夸张透视或密集装饰。
```

### 夜间封面编辑提示词

夜间版本应使用已确认的日间封面作为唯一图像输入，不重新生成构图。

```text
把输入的日间竖版封面转换为同一地点、同一镜头、同一主体和同一构图的夜间版本。

严格保留所有物体的位置、比例、轮廓、相机高度和焦距，不新增或删除主体。把环境改为深蓝黑夜色，加入克制的冷青反射光与少量局部指示光；暗部仍保留材质纹理和层次，不压成纯黑。整体安静、精确、具有档案系统般的技术感，但不是霓虹广告。

保持严格 9:16。不要生成文字、Logo、人物、伪 UI、额外屏幕、彩色灯带、强烈洋红色、过量辉光或雨幕遮挡。
```

## 竖长封面视频

### 输出规范

- 比例：严格 9:16，与对应主题封面图完全一致。
- 时长：6–10 秒。
- 编码：优先 MP4/H.264，可补 WebM；网页不使用音轨。
- 播放：首尾可无缝循环，固定镜头，无推拉摇移，无变焦。
- 动态幅度：低；只让画面中已有元素轻微运动。
- 不扩展成横版，不改变主体位置，不重新设计场景。

### 图生视频通用提示词

```text
以输入的 9:16 竖版合集封面为唯一视觉基准，生成 8 秒无缝循环视频。

保持原图的镜头、构图、主体位置、色彩关系、材质和纵横比完全不变。相机绝对固定，不推近、不拉远、不平移、不旋转。只让原画中合理的局部元素发生低幅度运动，例如自然光影缓慢移动、树叶轻摆、雨滴沿玻璃滑落、指示灯轻微呼吸、屏幕反光缓慢变化、空气微粒极少量漂浮。第一帧与最后一帧在光线、物体位置和运动相位上自然衔接。

严格 9:16，6-10 秒，无声。不要新增物体、人物、文字、Logo、伪 UI、镜头运动、景深抽动、画面闪烁、结构形变、液化、快速粒子或大范围环境变化。
```

### 日间动态建议

- 光斑缓慢移动。
- 纸张、窗帘、叶片有极轻微摆动。
- 局部反射或设备指示灯缓慢变化。
- 避免明显昼夜变化和大范围云层延时。

### 夜间动态建议

- 雨滴、冷色反光或局部指示灯轻微运动。
- 远处光源缓慢呼吸，不能频闪。
- 暗部保持稳定，避免自动曝光来回变化。

## 页面背景图

### 输出规范

- 比例：严格 16:9，建议 `1920 × 1080` 或更高。
- 页面背景是空间环境，不是视觉主体。
- 中央及主要内容区域保持低细节、低对比，边缘可以提供材质和光线线索。
- 合集首页背景必须能同时承载左侧合集轮播、中央封面和右侧资料面板。
- 单个合集详情背景可以体现主题，但不能抢过竖长封面。

### 日间页面背景提示词

```text
为个人博客的合集页面生成一张 16:9 日间空间背景。

主题：{合集主题或“多主题知识档案”}
空间隐喻：{工作室、档案室、书房、实验台、自然观察空间等}

自然柔和日光，低饱和暖中性色，真实材质，克制而高级。画面四周提供少量空间和材质细节，中央与主要内容区域保持低细节、低对比和稳定亮度，能够叠加半透明中文界面、竖长封面和文章资料。背景只负责氛围，不出现抢眼主体。

严格 16:9。不要生成文字、书名、Logo、人物、UI 面板、手机、强透视、杂乱桌面或高对比焦点。
```

### 夜间页面背景编辑提示词

```text
把输入的日间 16:9 页面背景转换为完全相同构图的夜间版本。

保留相机、空间结构、物体位置和中央低细节安全区。改为深蓝黑环境光，加入少量冷青材质反射和远处微弱灯光；暗部有层次但不纯黑，确保上方中文界面仍清晰可读。夜间版本只改变光线和时间，不重新设计空间。

不要生成文字、Logo、人物、伪 UI、强霓虹、洋红色主光、频闪灯、密集雨线或新的视觉主体。
```

## 生成顺序

1. 根据合集名称、描述和代表文章提取 3–6 个内容关键词。
2. 先确认日间竖长封面，构图不合格时不要继续生产夜间和视频。
3. 以日间封面作为唯一输入生成夜间封面。
4. 分别以日间、夜间封面生成对应 9:16 循环视频。
5. 需要时生成单个合集的 16:9 页面背景；首页背景单独生成。
6. 人工质检后上传 CDN，再填写后台日间/夜间视觉字段。

## 质检清单

- [ ] 图片和视频均符合目标比例，没有被工具自动裁成近似比例。
- [ ] 昼夜版本的主体、构图和焦点位置一致。
- [ ] 没有文字、Logo、水印、人物特写或第三方 IP。
- [ ] 9:16 封面在桌面与移动端 `object-fit: cover` 下主体仍完整。
- [ ] 视频固定镜头、低运动幅度、无闪烁，首尾循环无明显跳变。
- [ ] 视频没有音轨依赖，静音播放仍表达完整。
- [ ] 16:9 背景中央低细节，叠加页面后文字对比度合格。
- [ ] 资源使用稳定的 `https://static.nnnnzs.cn/...` CDN URL。
- [ ] 日间、夜间分别在前台首页和详情页实际切换验证。
